# Passione Fantascienza

Landing page del gruppo Telegram **Passione Fantascienza**.

Gruppo: <http://t.me/fantascienza1>

## Sviluppo

Il sito è statico e per ora non richiede build.

- sorgente pubblico: `dist/`
- deploy: GitHub Pages via GitHub Actions

Per anteprima locale:

```sh
python3 -m http.server 4173 -d dist
```

Poi aprire <http://localhost:4173/>.
